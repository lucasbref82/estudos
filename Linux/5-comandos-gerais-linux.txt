Comandos uteis para consultar informacoes do sistema,
gerenciar usuarios e controlar a maquina.


UNAME - INFORMACOES DO SISTEMA
--------------------------------

O uname retorna informacoes sobre o kernel e o hardware.
Util quando voce precisa saber o que esta rodando na maquina.

uname          - retorna nome e versao do kernel
uname -s       - nome do kernel
uname -n       - nome do usuario na rede
uname -r       - release do kernel
uname -v       - versao do kernel
uname -m       - nome do hardware
uname -p       - tipo do processador
uname -i       - plataforma do hardware
uname -o       - sistema operacional
uname -a       - retorna todos os dados acima de uma vez


COMANDOS DO DIA A DIA
----------------------

clear          - limpa o console
who            - mostra qual usuario esta logado
free           - mostra consumo e uso de memoria RAM


SUDO - SUPER USUARIO
---------------------

O sudo permite executar comandos como administrador do sistema.
Sem ele voce nao consegue instalar programas, editar arquivos
do sistema ou alterar configuracoes globais.

sudo <comando>  - executa o comando como super usuario
sudo su         - entra como usuario root no sistema


SHUTDOWN - DESLIGAR E REINICIAR
---------------------------------

shutdown           - desliga a maquina
shutdown -r        - reinicia a maquina
shutdown now       - desliga agora sem esperar
shutdown -r now    - reinicia agora sem esperar


MAN - MANUAL DOS COMANDOS
---------------------------

O man e seu melhor amigo quando voce nao lembra o que um
comando faz ou quais opcoes ele aceita.

man <comando>   - abre o manual completo do comando

    ex: man find
    ex: man chmod
    ex: man ls


TOUCH - CRIAR E ALTERAR DATAS DE ARQUIVOS
------------------------------------------

O touch serve para criar arquivos vazios ou alterar a data
de acesso e modificacao de um arquivo que ja existe.

touch <arquivo>    - cria o arquivo se nao existir
                     se ja existir, atualiza a data de modificacao

O formato de data e: AAAAMMDDHHMM
- AAAA - ano com 4 digitos
- MM   - mes
- DD   - dia
- HH   - hora
- MM   - minuto

touch -m -t 202607281400 <arquivo>   - altera a data de modificacao
touch -a -t 202607281400 <arquivo>   - altera a data de acesso

    -m - modification - data de modificacao
    -a - access - data de acesso
